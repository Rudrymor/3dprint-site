## Variant: Clean Light

### Design stance
Чистый светлый дизайн с синим акцентом. Дружелюбный, современный, легко воспринимается широкой аудиторией.

### Key choices
- Layout: двухколоночный hero, карточки с тенями
- Typography: Plus Jakarta Sans (круглый, дружелюбный)
- Color: белый фон (#fafaf9), синий акцент (#2563eb), фиолетовый градиент
- interaction: hover-эффекты с тенями, кнопки с иконками

### Trade-offs
- Strong at: доступность, доверие, широкая аудитория
- Weak at: менее «технический» вид, может быть слишком generic

### Best for
Широкая аудитория, клиенты ценящие профессионализм и доступность.
