## Variant: Industrial Minimal

### Design stance
Чистый индустриальный минимализм с акцентом на структуру и иерархию. Шрифт Space Grotesk создаёт технический характер.

### Key choices
- Layout: сетка с чёткими колонками, много воздуха
- Typography: Space Grotesk (заголовки) + Inter (текст), много uppercase
- Color: чёрный фон (#0a0a0a), оранжевый акцент (#ff6b35)
- Interaction: hover-эффекты с подъёмом карточек, плавные переходы

### Trade-offs
- Strong at: профессиональный технический вид, чёткая иерархия
- Weak at: может быть слишком холодным для широкой аудитории

### Best for
Техническая аудитория, инженеры, люди ценящие минимализм и точность.
