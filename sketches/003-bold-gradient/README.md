## Variant: Bold Gradient

### Design stance
Современный градиентный дизайн с неоновыми акцентами. Динамичный, привлекающий внимание, с элементами glassmorphism.

### Key choices
- Layout: центрированный hero, карточки с полупрозрачными фонами
- Typography: Outfit (современный, геометрический)
- Color: чёрный фон (#09090b), градиенты cyan → purple → pink
- Interaction: анимированные градиенты, пульсирующие элементы, glow-эффекты

### Trade-offs
- Strong at: визуальное воздействие, современность, запоминаемость
- Weak at: может отвлекать от контента, сложнее для восприятия

### Best for
Молодая аудитория, креативные проекты, бренды выделяющиеся на фоне конкурентов.
