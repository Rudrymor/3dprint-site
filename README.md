# 🖨️ Сайт 3D-печати на заказ

Привет! Это твой сайт для приёма заказов на 3D-печать.
Всё работает бесплатно, управлять можно без программирования.

---

## 📋 Как добавить новый проект в каталог

1. Открой файл **`scripts/catalog.js`** в Блокноте
2. Найди конец массива (последняя строка с `]` перед `;`)
3. Добавь запятую после последней `}` и вставь новый блок:

```js
  ,
  {
    "id": 11,
    "name": "Название детали",
    "description": "Краткое описание что это и для чего",
    "image": "images/foto-nazvanie.jpg",
    "category": "techno",
    "material": "PLA / PETG",
    "price_s": "450 ₽",
    "price_m": "680 ₽",
    "price_l": ""
  }
```

4. Сохрани файл (Ctrl+S)

**Поля:**

| Поле | Что писать | Пример |
|------|-----------|--------|
| `id` | Уникальный номер (следующий по порядку) | `11` |
| `name` | Короткое имя | Чехол для ключа BMW |
| `description` | Что это и для чего | Защитный чехол, PLA, 2 цвета |
| `image` | Путь к фото | `images/bmw-cover.jpg` |
| `category` | Категория (см. ниже) | `techno` |
| `material` | Материал печати | PETG / ABS |
| `price_s` | Цена маленький | `320 ₽` |
| `price_m` | Цена средний | `580 ₽` |
| `price_l` | Цена большой (оставь пустым если нет) | `850 ₽` |

**Категории:**

| Значение | Что это | Примеры |
|----------|---------|---------|
| `techno` | Технические детали, запчасти, крепления | Шестерни, кронштейны, чехлы, заглушки |
| `decor` | Игрушки, декор, фигурки | Ночники, статуэтки, сувениры |

## 🐱 Фигурка в шапке главной страницы

Справа в блоке услуг стоит вырезанная фигурка (фон убран). Слева — анимированный принтер, так что композиция симметричная.

Когда раскрасишь фигурку и сфотографируешь её заново — замену можно сделать одной командой (нужен установленный Python):

```bash
python tools/figure_cutout.py --in "новое-фото.jpg" --out images/figure-hero.webp
```

Скрипт сам найдёт фигурку на фото, уберёт фон и подрежет кадр. Разметку на сайте менять не нужно — имя файла остаётся тем же.

**Как снимать, чтобы получилось резко:**
- фигурка целиком в кадре, крупно: её высота на фото — **от 900 px** (иначе при увеличении на сайте будет мыло);
- фон — однотонный и заметно темнее фигурки (стол, лист бумаги не подойдут: светлое слипнется с фигуркой);
- свет мягкий, без жёстких бликов;
- руку в кадр не заводить (в прошлом фото рука держала фигурку за кепку — на сайте её пришлось вырезать).

Если фон оказался другим (например, светлый стол), скажи — подберу пороги `--bright` / `--sat` под твоё фото.

##  Как посмотреть заявки

Заявки с сайта приходят **в Telegram** — бот отправит сообщение с данными клиента.
Если что-то не доходит — напиши, разберёмся.

---

## 💬 Как добавить отзывы

1. Открой файл **`scripts/reviews.js`**
2. Найди массив `const REVIEWS_DATA = [` — сейчас он пустой
3. Вставь отзыв по образцу (образец есть в комментариях файла):

```js
  {
    "name": "Алексей",
    "text": "Заказывал кронштейн для регистратора. Сделали за два дня, встал как родной.",
    "rating": 5,
    "date": "Август 2026"
  },
```

4. Сохрани файл (Ctrl+S)

Пока отзывов нет — секция целиком скрыта на сайте. Добавишь первый — она появится сама.

## ⚙️ Технические детали

```
3dprint-site/
├── index.html          ← главная страница
├── works.html          ← каталог работ (клик по фото = лайтбокс)
├── order.html          ← страница заявки + таблица материалов
├── reviews.html        ← книга клиентов (отзывы)
├── images/             ← фотографии работ + фигурка для шапки
├── styles/main.css     ← общие стили всех страниц
├── scripts/
│   ├── catalog.js      ← каталог товаров (редактируй это!)
│   ├── reviews.js      ← отзывы клиентов (редактируй это!)
│   └── common.js       ← мелкие утилиты (меню, защита от вставки кода)
├── tools/figure_cutout.py ← вырезает фигурку с фото для шапки
├── sketches/           ← черновики дизайна (на сайт не влияют)
├── README.md           ← этот файл
└── .gitignore
```

**Важно для правок:** ассеты подключаются с версией (`styles/main.css?v=4`, `scripts/*.js?v=…`). GitHub Pages кэширует статику 10 минут, поэтому после правки CSS или скриптов номер версии нужно поднять — иначе посетители увидят старый файл.

**Деплой:** при каждом push в ветку `main` сайт обновляется автоматически на GitHub Pages.

##  Частые вопросы

**Товар не появляется в каталоге**
→ Проверь, что не пропустил запятую между блоками `{}`
→ Убедись, что фото существует по указанному пути

**Хочу изменить текст на сайте**
→ Напиши мне, я поправлю HTML.

**Сайт не открывается**
→ Проверь ссылку: `https://ТВОЙ_НИК.github.io/3dprint-site/`
→ Если не работает — возможно, GitHub Pages не включён в настройках репозитория.
