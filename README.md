# 🖨️ Сайт 3D-печати на заказ

Привет! Это твой сайт для приёма заказов на 3D-печать.
Всё работает бесплатно, управлять можно без программирования.

---

## 📋 Как добавить новый товар в каталог

1. Открой Google Таблицу: **ссылку пришлю отдельно**
2. Добавь новую строку и заполни столбцы:

| Столбец | Что писать | Пример |
|---------|-----------|--------|
| `Название` | Короткое имя товара | Кронштейн для монитора |
| `Описание` | Что это и для чего | Крепление монитора к стене, до 27" |
| `Фото` | Ссылка на изображение | https://i.imgur.com/abc123.jpg |
| `Материал` | Из чего печатается | PETG |
| `Цена S` | Цена за маленький размер | 450 ₽ |
| `Цена M` | Цена за средний размер | 680 ₽ |
| `Цена L` | Цена за большой размер | 950 ₽ |

3. Сайт обновится **автоматически** в течение 5 минут.

**Где взять ссылку на фото?**
- Загрузи фото на [imgur.com](https://imgur.com) (бесплатно, без регистрации)
- Нажми «Get share links» → скопируй «Direct link» (заканчивается на `.jpg` или `.png`)

##  Частые вопросы

**Клиент не может открыть форму**
→ Скорее всего, у него блокировщик рекламы. Попроси отключить или написать напрямую.

**Товар не появляется в каталоге**
→ Проверь, что таблица открыта по ссылке «Anyone with the link can view».
→ Убедись, что все столбцы заполнены (особенно `Название` и `Фото`).

**Хочу изменить текст на сайте**
→ Напиши мне, я поправлю HTML. Самостоятельно — только если освоишь Git.

**Сайт не открывается**
→ Проверь ссылку: `https://ТВОЙ_НИК.github.io/3dprint-site/`
→ Если не работает — возможно, GitHub Pages не включён в настройках репозитория.
