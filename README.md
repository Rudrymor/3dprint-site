# 🖨️ Сайт 3D-печати на заказ

Привет! Это твой сайт для приёма заказов на 3D-печать.
Всё работает бесплатно, управлять можно без программирования.

---

## 📋 Как добавить новый проект в каталог

1. Открой файл **`scripts/catalog.js`** в Блокноте
2. Найди конец массива (последняя строка с `]` перед `;`)
3. Добавь запятую после последней `}` и вставь новый блок:

```js
  ,
  {
    "id": 11,
    "name": "Название детали",
    "description": "Краткое описание что это и для чего",
    "image": "images/foto-nazvanie.jpg",
    "category": "techno",
    "material": "PLA / PETG",
    "price_s": "450 ₽",
    "price_m": "680 ₽",
    "price_l": ""
  }
```

4. Сохрани файл (Ctrl+S)

**Поля:**

| Поле | Что писать | Пример |
|------|-----------|--------|
| `id` | Уникальный номер (следующий по порядку) | `11` |
| `name` | Короткое имя | Чехол для ключа BMW |
| `description` | Что это и для чего | Защитный чехол, PLA, 2 цвета |
| `image` | Путь к фото | `images/bmw-cover.jpg` |
| `category` | Категория (см. ниже) | `techno` |
| `material` | Материал печати | PETG / ABS |
| `price_s` | Цена маленький | `320 ₽` |
| `price_m` | Цена средний | `580 ₽` |
| `price_l` | Цена большой (оставь пустым если нет) | `850 ₽` |

**Категории:**

| Значение | Что это | Примеры |
|----------|---------|---------|
| `techno` | Технические детали, запчасти, крепления | Шестерни, кронштейны, чехлы, заглушки |
| `decor` | Игрушки, декор, фигурки | Ночники, статуэтки, сувениры |

## 📸 Как добавить фото

Положи фото в папку `images/` и укажи путь: `images/moyo-foto.jpg`

**Или** загрузи на [imgur.com](https://imgur.com) → скопируй «Direct link» → вставь в поле `image`.

## 🚀 Как работает сайт

- Хостинг: **GitHub Pages** (бесплатно)
- Форма заказа: **Tally.so** (встроена в сайт)
- Каталог товаров: встроен в **`scripts/catalog.js`** (ты редактируешь — сайт показывает)
- Уведомления: **Telegram-бот** (присылает заявки тебе)

##  Частые вопросы

**Товар не появляется в каталоге**
→ Проверь, что не пропустил запятую между блоками `{}`
→ Убедись, что фото существует по указанному пути

**Хочу изменить текст на сайте**
→ Напиши мне, я поправлю HTML.

**Сайт не открывается**
→ Проверь ссылку: `https://ТВОЙ_НИК.github.io/3dprint-site/`
→ Если не работает — возможно, GitHub Pages не включён в настройках репозитория.
